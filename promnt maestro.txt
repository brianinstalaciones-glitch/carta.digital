# 🧠 PROMPT MAESTRO — CARTA DIGITAL INTERACTIVA

> Listo para usar en VS Code + GitHub Copilot, Cursor, Windsurf o cualquier agente de IA

-----

## 📌 CONTEXTO DEL PROYECTO

Estás trabajando en una **Carta Digital Interactiva** para restaurantes, bares y cafeterías.
El archivo principal es `carta-app.html` — una Single Page Application (SPA) en HTML/CSS/JS puro.

El producto ofrece:

- Menú digital visual e interactivo (sin app, sin QR externo)
- Panel de administración para editar platos, precios e imágenes
- Modo demo gratuito de **15 días** antes de contratar

```

Debe incluir:

### TAREA 2 — Sistema de Prueba Gratuita de 15 Días

```
Crea el archivo trial/trial-manager.js con la siguiente lógica:

FUNCIONES REQUERIDAS:
- initTrial()         → Inicia el período de prueba y guarda fecha en localStorage
- checkTrialStatus()  → Retorna { active: bool, daysLeft: number, expired: bool }
- showTrialBanner()   → Muestra banner con días restantes en la interfaz
- showExpiredModal()  → Modal al expirar con CTA para contratar
- resetTrial()        → Solo para desarrollo/demo (borra localStorage)

COMPORTAMIENTO:
- Al primer acceso: guarda timestamp en localStorage['cartaDigital_trialStart']
- Calcula días restantes = 15 - días transcurridos
- Si daysLeft <= 3: banner se vuelve urgente (color rojo/naranja)
- Si expired === true: bloquea la app y muestra modal de conversión
- El modal de expiración tiene: mensaje de agradecimiento + botón WhatsApp + botón Email

EJEMPLO DE USO:
const trial = new TrialManager();
trial.init();
// → Muestra "✨ 13 días restantes de prueba gratuita"
```

### TAREA 5 — Componente Banner de Prueba (UI)

```
Añade en carta-app.html un banner de prueba con este comportamiento visual:

ESTADOS:
1. días 1-12:  Fondo dorado sutil → "✨ Prueba tu carta digital GRATIS — X días restantes"
2. días 13-14: Fondo naranja → "⏳ Solo X días restantes — ¡Contáctanos para continuar!"
3. día 15:     Fondo rojo → "🔔 Último día de prueba — Activa tu carta hoy"
4. expirado:   Modal de pantalla completa con CTA

El banner debe tener:
- Botón X para cerrarlo temporalmente (se vuelve a mostrar al recargar)
- Enlace directo a WhatsApp con mensaje pre-escrito
- Animación de entrada suave (slide-down)

Mensaje WhatsApp pre-escrito:
"Hola, estoy probando la carta digital y me interesa contratar el servicio. ¿Pueden darme información?"
```

```

## 🚀 FLUJO DE EXPERIENCIA DEL USUARIO (UX)

```
1. El restaurante recibe el archivo carta-app.html
2. Abre en navegador → ve su menú funcionando (datos de ejemplo)
3. Ve el banner: "✨ 15 días de prueba gratuita — Sin tarjeta de crédito"
4. Puede explorar todos los platos, filtrar, buscar
5. Entra al panel admin (/admin/panel.html) y personaliza su menú
6. Los cambios se ven en tiempo real en carta-app.html
7. Al día 13 recibe aviso urgente de expiración
8. Al expirar → modal con botón de WhatsApp para contratar
9. Tras contratar → se elimina el TrialManager y la app queda limpia
```
